Presence · Onboarding Design

Tutorial First-Exercise

Three options for the very first thing a new user does — grounded in the actual code, not invented. Goal: maximize first-session retention without pretending Presence is frictionless wellness. It's serious Bardon training; the opener has to respect that.

How it works today

Verified in presence.html:

  • Tutorial → _tutorialFirstClock = true → currentExercise = 'clock' → startConcentration() (~line 21354).
  • Beginner gets a stripped UI — only Begin → wait → Stop (line 7941).
  • Pre-instruction shown up front (line 7953):
"Focus on the tip of the seconds hand. Click Stop the second a thought appears. Nothing must distract you inside or outside of your mind. The moment you are distracted you MUST stop. For this first exercise, as a beginner, you will only go max 60 seconds."
  • Experienced path copy (line 7954): "Be pitiless with yourself. No ego here…"
  • Begin → 5s countdown → clock runs. Beginner has a 60s auto-stop (line 8030).
  • On stop: a single raw second count (line 8080) → save → reward → post-session overlay.
The core problem. The hold is inert (no interaction for up to 60s), the framing is pitiless ("you MUST stop"), and the only output is a bare number that, for a cold beginner (~15–30s), reads as a failing grade. Reordering the surrounding tutorial screens does nothing about the exercise itself.

Full roster (concentration): Clock, Visualization, Auditory, Thought Control, Asana. Plus Awareness (Tolle witness). Thought Control already has a "tap each intrusion + running count" mechanic.

Option AReframe the Clock run as "returns"

Effort · Medium Gentle win

Keep Clock and the existing 60s structure, but flip framing + scoring for the tutorial run only.

Changes

  • Replace label60 with a returns-based frame:
"Rest your eyes on the tip of the seconds hand. The moment you notice your attention has drifted, gently bring it back — and tap. Each return is one rep."
  • Add a tap-anywhere-to-count-returns interaction during the hold (reuse Thought Control's tap → ripple + count + Akasha mote), counting returns positively.
  • Drop the self-stop-on-failure instruction; let the existing 60s cap run to completion.
  • Result: instead of raw seconds → "You returned N times — N reps of attention." Award XP/Akasha off N (floor of 1).
  • Post-session Omnia: "Returning is the exercise. That muscle is what every step builds."

Why it works

Can't-fail (every return scores), interactive, inoculates against the #1 beginner quit reason ("my mind won't stop"). Stays inside the real Clock exercise.

Risk

The tutorial Clock now teaches the opposite rule from the real Clock met later ("Stop when focus breaks"). Needs a bridge: "That was training wheels — the real Clock asks you to stop on the first thought. Ready?"

Option BOpen with Thought Control instead

Effort · Med-High Forgiving by nature

Swap the tutorial opener from clock to thought.

Changes

  • Launch thought-control in a new _tutorialFirstThought mode (60s cap, stripped UI, post-session hook).
  • Reframe first-run copy from "Think of nothing. Tap each intrusion." →
"Let your mind settle. Each time you notice a thought arrive, tap. Noticing it is the skill — not silencing it."
  • It already doesn't end on failure and has tap-to-record + a live count.
  • Result: invert the count's meaning for run #1 only — "You noticed N thoughts — N moments of awareness." (Normally more intrusions = worse, so the copy must flip it.)
  • Post-session Omnia explains real Thought Control + that noticing underlies all concentration.

Why it works

Uses an exercise that's already forgiving (runs to time, counts rather than terminates). The tap interaction is built in.

Risk

"Tap each intrusion" inherently scores weakness; inverting its meaning for one run then flipping it back later can confuse. The tutorial scaffolding (60s cap, stripped UI, post-session) is currently clock-specific — you'd add a parallel path or generalize it. More plumbing than A.

Option CKeep Clock, frame the number as a baseline

Effort · Low Honest training

Keep all mechanics as-is. Change only copy + post-session framing.

Changes

  • Soften label60 from "pitiless / you MUST stop" to a baseline frame:
"See how long you can rest on the tip of the seconds hand before a thought pulls you away. However long you last is your starting line — we'll grow it together."
  • Result: present rawSecs as "Your baseline: N seconds" with a forward note, not pass/fail.
  • Post-session Omnia: "Most people start near here. In a week this number climbs — that climb is the practice." Tie to the streak/XP they're about to earn.

Why it works

Honest, on-brand for a rigorous niche; reframes a weak first number as a hook ("watch it grow") instead of a verdict. Zero new interaction risk.

Risk

Still an inert, non-interactive 60s stare. The "win" is purely narrative — does the least to manufacture engagement, leans hardest on an audience that already wants rigor.
